# Connecter votre client IA à Adobe Learning Manager

## Présentation

Votre administrateur d’intégration doit d’abord configurer le connecteur. Si vous ne voyez pas de connecteur Adobe Learning Manager, contactez votre administrateur. **Le connecteur est disponible uniquement pour les comptes Adobe Learning Manager Ultimate**. Les administrateurs peuvent afficher [Ajouter Adobe Learning Manager à votre client IA d&#39;entreprise](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md).

1. Ouvrez le client IA de votre organisation, tel que Claude ou ChatGPT Enterprise.
2. Recherchez le connecteur Adobe Learning Manager dans la liste des connecteurs.
3. Sélectionnez **Se connecter**.
4. Authentifiez la connexion et fournissez les détails de votre compte Adobe Learning Manager lorsque vous y êtes invité.
5. Posez une question sur votre apprentissage. Pour des idées, découvrez les [exemples d’invite pour les élèves](/help/migrated/learners/feature-summary/sample-prompts-for-learners.md).

>[!NOTE]
>
>Authentifiez-vous une fois. Vos demandes s’exécutent avec vos propres autorisations. Vous ne voyez donc que ce à quoi vous pouvez accéder dans Adobe Learning Manager.

## Dépannage

**Le connecteur est introuvable**
Demandez à votre administrateur d’activer le connecteur pour vous.

**Le client IA ne se souvient pas de votre question précédente**
Le serveur traite chaque demande comme nouvelle. La suite d’une conversation dépend de votre client AI. Reprenez les détails pertinents dans votre prochaine question.

**Le client AI n’appelle pas le connecteur Adobe Learning Manager**
Nommez ce que vous souhaitez dans votre question, par exemple vos inscriptions ou un sujet de cours.
