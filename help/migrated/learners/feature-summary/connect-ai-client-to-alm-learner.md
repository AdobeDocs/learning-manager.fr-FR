# Connecter votre client IA à Adobe Learning Manager

Votre administrateur d’intégration doit d’abord configurer le connecteur. Si vous ne voyez pas de connecteur Adobe Learning Manager, contactez votre administrateur. **Le client n&#39;est disponible que pour le niveau Adobe Learning Manager Ultimate**.

Les administrateurs peuvent se reporter à la section [Ajout de Adobe Learning Manager à votre client AI](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md).

1. Ouvrez le client IA de votre organisation, tel que Claude ou ChatGPT Enterprise.
2. Recherchez le connecteur Adobe Learning Manager dans la liste des connecteurs.
3. Sélectionnez **Se connecter**.
4. Connectez-vous avec l’identité de votre entreprise lorsque vous y êtes invité.
5. Posez une question sur votre apprentissage. Pour des idées, consultez **exemples d’invites pour les élèves**.

>[!NOTE]
>
>Connectez-vous une fois. Vos demandes s’exécutent avec vos propres autorisations. Vous ne voyez donc que ce à quoi vous pouvez accéder dans Adobe Learning Manager.

## Dépannage

**connecteur introuvable**

Demandez à votre administrateur d’activer le connecteur pour vous.

**Le client IA ne se souvient pas de votre question précédente**

Chaque demande est traitée comme nouvelle. La suite d’une conversation dépend de votre client AI. Répétez les détails dans votre question suivante.

**Le client IA n&#39;appelle pas le connecteur Adobe Learning Manager**

Nommez ce que vous souhaitez dans votre question, par exemple vos inscriptions ou un sujet de cours.
