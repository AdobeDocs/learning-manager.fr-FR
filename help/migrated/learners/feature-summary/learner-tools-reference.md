# Outils d&#39;élève pour le serveur Model Context Protocol

Chaque fonctionnalité s’exécute en tant qu’élève connecté, une fois qu’il se connecte. Une demande renvoie uniquement ce à quoi l’élève peut accéder dans Adobe Learning Manager. Voir [Connecter votre client IA](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md) pour plus d&#39;informations.

## Capacités de l’élève

| **Capacité** | **Ce que les élèves peuvent faire** | **Exemple de requête** |
|----|----|----|
| Rechercher du contenu d’apprentissage | Trouver des cours, des certifications et des parcours d’apprentissage | Quels sont les cours de leadership disponibles ? |
| Afficher les inscriptions | Vérifier les inscriptions et la formation requise | Lequel de mes cours est sur le point d’expirer ? |
| Poser des questions d’apprentissage | Obtenir des réponses à partir du contenu d’apprentissage | Que signifie la gestion des risques de la chaîne d’approvisionnement dans FedRAMP ? |
| Générer des parcours d’apprentissage | Créer des parcours d’apprentissage personnalisés | Aidez-moi à trouver des cours pour perfectionner mes compétences en gestion de projet. |
| Enregistrer les parcours d’apprentissage | Enregistrer les parcours d’apprentissage générés | Enregistrez ce parcours d’apprentissage. |

## Outils MCP pris en charge

Le serveur MCP Learner Assistant expose les outils suivants destinés aux élèves.

| **Outil MCP** | **Objectif** | **Prise en charge de la fonctionnalité** |
|----|----|----|
| Recherche | Rechercher dans le contenu d’apprentissage disponible | Rechercher du contenu d’apprentissage |
| Obtenir l’inscription | Récupérer les informations d&#39;inscription des élèves | Afficher les inscriptions |
| Agent de réponse | Répondre aux questions à l’aide du contenu d’apprentissage | Poser des questions d’apprentissage |
| Obtenir l’utilisateur | Identifier l’élève connecté pour chaque demande | Toutes les fonctionnalités |
| Obtenir l’objet d’apprentissage | Récupérer les détails d’un objet d’apprentissage, tels que la description et la durée | Rechercher du contenu d’apprentissage, Afficher les inscriptions |
| Générer un parcours d’apprentissage | Création de parcours d’apprentissage recommandés | Générer des parcours d’apprentissage |
| Enregistrer le parcours d’apprentissage | Enregistrer les parcours d’apprentissage générés | Enregistrer les parcours d’apprentissage |

>[!IMPORTANT]
>
>Les noms des outils sont affichés à titre de référence et peuvent varier en fonction de la mise en œuvre du client.
