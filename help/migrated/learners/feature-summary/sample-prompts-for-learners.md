# Exemples d’invites pour les élèves Adobe Learning Manager

Vous devez d’abord connecter votre client AI. Affichez [Connecter votre client AI](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md). Chaque invite est mappée à un outil dans la [référence des outils de l’élève](/help/migrated/learners/feature-summary/learner-tools-reference.md).

## Inscriptions

| **Invite** | **Outil** |
|------------------------------------------|----------------|
| Dans quels cours suis-je inscrit ? | Obtenir l’inscription |
| Lequel de mes cours est sur le point d’expirer ? | Obtenir l’inscription |

## Recherche

| **Invite** | **Outil** |
|-----------------------------------------|----------|
| Quels sont les cours de leadership disponibles ? | Recherche |
| Afficher la formation à la sécurité disponible. | Recherche |

## Connaissances

| **Invite** | **Outil** |
|---------------------------------------------------------|--------------|
| Que signifie la gestion des risques de la chaîne d’approvisionnement dans FedRAMP ? | Agent de réponse |
| Expliquez les exigences de mon cours sur la conformité. | Agent de réponse |

## Parcours d’apprentissage

| **Invite** | **Outil** |
|----|----|
| Aidez-moi à trouver un ensemble de cours pour améliorer mes compétences en gestion de projet. | Générer le parcours d’apprentissage |
| Enregistrez ce parcours d’apprentissage. | Enregistrer le parcours d’apprentissage |
