# Cours adaptatifs pour les élèves

## Introduction

Les cours adaptatifs dans Adobe Learning Manager sont des cours qui vous sont demandés par votre auteur en évaluant vos besoins d’apprentissage et en les personnalisant en fonction de vos besoins d’apprentissage une fois que cette fonctionnalité est activée par votre administrateur. Pour plus d&#39;informations, voir [Cours adaptatifs](/help/migrated/administrators/feature-summary/adaptive-course-admin.md).

## Suivre un cours adaptatif en tant qu’élève

Lorsque vous suivez un cours adaptatif dans Adobe Learning Manager, vous voyez un ensemble personnalisé de modules en fonction des groupes d’utilisateurs auxquels vous appartenez.

### Ce que vous voyez lorsque vous ouvrez un cours adaptatif

Lorsque vous ouvrez un cours adaptatif, seuls les modules qui vous concernent s&#39;affichent. Les modules affectés à d’autres groupes d’utilisateurs ne sont pas visibles du tout.

Votre barre de progression d’achèvement et le nombre « X sur Y modules terminés » reflètent uniquement vos modules requis. Votre collègue inscrit au même cours peut voir un nombre différent de modules, une combinaison différente de obligatoires et facultatifs, ou un ensemble entièrement différent de contenus, tous en fonction de leurs groupes d’utilisateurs.

### S&#39;inscrire à un cours adaptatif

L&#39;inscription à un cours adaptatif fonctionne de la même manière que l&#39;inscription à n&#39;importe quel cours. Vous pouvez vous auto-inscrire à partir du catalogue ou votre administrateur peut vous inscrire.

![](assets/image_0010.png)

Si aucun module n&#39;est visible dans le cours en fonction de vos groupes d&#39;utilisateurs actuels, vous ne pouvez pas vous inscrire. Si cela se produit, contactez votre administrateur. Cela signifie probablement que votre affectation de groupe d’utilisateurs doit être mise à jour.

### Navigation dans les modules du lecteur

Lorsque vous ouvrez le lecteur de cours, la table des matières sur la gauche affiche uniquement les modules que vous pouvez voir. Vous pouvez utiliser les boutons de navigation pour parcourir vos modules dans l&#39;ordre (pour les cours ordonnés) ou accéder à n&#39;importe quel module dans n&#39;importe quel ordre (pour les cours non ordonnés).

Les modules qui appartiennent aux groupes d&#39;utilisateurs d&#39;autres élèves ne sont pas affichés dans votre table des matières.

### Comprendre vos exigences d’achèvement

Votre cours est terminé lorsque vous avez terminé tous les modules étiquetés **Requis**. Les modules facultatifs ne bloquent pas l’achèvement. Vous pouvez les terminer, les revoir ou les ignorer complètement sans affecter votre progression vers l’achèvement.

### Que se passe-t-il si une salle de classe ou une session de classe virtuelle est pleine ?

Si vous voyez une salle de classe ou un module de salle de classe virtuelle mais qu’il ne vous reste aucune place, vous êtes inscrit au cours et placé sur une liste d’attente pour cette session spécifique. Vous pouvez toujours accéder à tous les autres modules et les terminer immédiatement. Seule la session complète est en attente.

Pendant que vous êtes sur liste d’attente pour une session :

* La session apparaît dans votre lecteur de cours, mais vous ne pouvez pas la lancer ni y accéder.
* La progression globale du cours se poursuit normalement avec vos autres modules.
* Vous recevez une notification lorsqu’une place devient disponible et que vous êtes retiré de la liste d’attente.

Une fois qu’une place vous est attribuée, la session devient accessible et vous pouvez y participer ou la terminer.

### Que se passe-t-il lorsque votre profil change en cours de route ?

Votre expérience de cours adaptatif est liée à vos groupes d&#39;utilisateurs. Si vos groupes d’utilisateurs changent pendant votre inscription, par exemple, en raison de votre rôle ou de votre emplacement, votre module est mis à jour automatiquement.

* Si vos groupes d&#39;utilisateurs mis à jour vous permettent de voir les modules précédemment masqués, ces derniers apparaissent dans votre cours. S’ils sont requis pour votre nouveau profil, ils sont ajoutés à vos exigences d’achèvement.
* Si vos groupes d’utilisateurs mis à jour n’incluent plus de module, celui-ci est supprimé de votre vue. Si ce module était précédemment requis mais ne l’est plus, il est supprimé de votre nombre d’achèvements.
* Tout module que vous avez déjà terminé reste marqué comme terminé, même si vos groupes d’utilisateurs changent. Vous n&#39;avez pas besoin de rétablir le travail terminé, sauf si un module nouvellement visible n&#39;a pas été effectué auparavant.
* La date de début, les dates d’achèvement des modules terminés et l’enregistrement de la progression globale restent intacts quelles que soient les modifications apportées au profil.

### Que se passe-t-il une fois le cours terminé ?

Lorsque vous terminez tous les modules requis, le cours est marqué comme terminé. Vous recevez alors tout badge ou point de ludification applicable.

Une fois l’opération terminée, si vos groupes d’utilisateurs changent et que de nouveaux modules requis deviennent disponibles, votre achèvement peut être annulé et vous devrez peut-être terminer ces modules supplémentaires.

Dans ce cas :

* Votre achèvement d&#39;origine reste dans votre relevé de notes en tant qu&#39;enregistrement historique.
* Le cours s’ouvre à nouveau dans un état En cours affichant uniquement le nouveau travail requis.
* Il vous suffit de terminer les nouveaux modules requis.
* Vous recevez une notification lorsqu’une actualisation de votre achèvement est déclenchée.
