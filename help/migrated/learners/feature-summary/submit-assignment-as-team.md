# Envoi d’un devoir d’équipe dans Adobe Learning Manager

Visualisez votre équipe, travaillez ensemble sur le devoir, téléchargez un fichier pour toute l’équipe et vérifiez le résultat de l’évaluation de votre équipe.

Lorsque vous êtes affecté à une équipe, vous recevez une notification.

![Notification d&#39;affectation à une équipe](assets/Group-Team-submission-and-rubric-based-assessments-image30.png "Notification d&#39;affectation à une équipe")

Dans un module d’envoi de fichiers basé sur une équipe, n’importe quel membre de l’équipe peut télécharger le fichier pour tous les membres de l’équipe qui lui est associée. Votre instructeur évalue le travail une fois et le résultat s’applique à toute l’équipe.

## Voir votre équipe et le plan d’évaluation

1. Ouvrez le cours dans l’application de l’élève, puis accédez à la page de présentation du cours. Les activités d’équipe sont marquées comme activités d’équipe dans le plan de cours.

   ![Activité d&#39;équipe marquée dans le plan de cours](assets/Group-Team-submission-and-rubric-based-assessments-image31.png "Activité d&#39;équipe dans le plan de cours")

1. Sélectionnez **Afficher les membres de l&#39;équipe** pour afficher la liste des autres élèves qui font partie de la même équipe que vous.

   ![Liste des membres de l’équipe](assets/Group-Team-submission-and-rubric-based-assessments-image32.png "Membres de l’équipe")

1. Si vous ne faites pas encore partie d&#39;une équipe, un message vous informe que l&#39;activité commence après votre affectation à une équipe. Contactez votre instructeur ou votre administrateur.

1. Si l’auteur l’autorise, consultez les éléments qui vous serviront de base à votre évaluation. Vous pouvez lire la description du plan d&#39;évaluation et la description de chaque paramètre d&#39;évaluation. Vous ne pouvez pas afficher les options de réponse, les points ou la pondération.

Vous recevez une notification et un e-mail lorsque vous êtes ajouté à une équipe, supprimé d’une équipe ou lorsqu’un membre de l’équipe est ajouté ou supprimé.

## Envoyer le fichier de l’équipe

1. Sur la page de présentation du cours, ouvrez l’activité basée sur l’équipe.

1. Convenez avec votre équipe du fichier à soumettre. Sélectionnez **Charger**.

   ![Option de téléchargement pour l&#39;activité d&#39;équipe](assets/Group-Team-submission-and-rubric-based-assessments-image33.png "Option de téléchargement")

1. Chargez le fichier. Le statut passe à **Évaluation en attente**. Vous pouvez toutefois examiner votre soumission et soumettre un autre fichier.

   ![Statut d&#39;évaluation en attente après le téléchargement](assets/Group-Team-submission-and-rubric-based-assessments-image34.png "Statut d&#39;évaluation en attente")

Votre instructeur est averti. Chaque membre de l’équipe peut consulter le statut et le fichier envoyé, puis le télécharger. Tous les membres de l’équipe reçoivent une notification et un e-mail lorsqu’un membre envoie ou renvoie son projet.

Pour remplacer le fichier avant qu&#39;il ne soit approuvé, sélectionnez **Afficher**/**Modifier l&#39;envoi**, puis chargez un nouveau fichier.

>[!NOTE]
>
>Si l’auteur n’a pas besoin de l’approbation du réviseur, l’activité se termine pour chaque membre de l’équipe dès l’envoi du fichier.

## Afficher le résultat

1. Ouvrez l’activité d’équipe une fois que votre instructeur l’a évaluée. Tous les membres de l’équipe reçoivent une notification.

1. Affichez le statut, par exemple Approuvé ou Refusé.

1. Lisez les commentaires de l&#39;instructeur, s&#39;il a choisi de les afficher.

1. Si l&#39;activité comporte un plan d&#39;évaluation, affichez le nom du réviseur, l&#39;option sélectionnée pour chaque paramètre d&#39;évaluation, les réponses écrites et les remarques éventuelles. Les points pour les options individuelles ne sont pas affichés.

1. Si le score est activé, affichez le score global de votre équipe.

Si l&#39;activité ne nécessite pas d&#39;approbation, vous voyez qu&#39;elle est évaluée, avec le résultat.

## Resoumettre après un rejet

Si l’envoi de votre équipe a été rejeté, lisez les commentaires, puis chargez un nouveau fichier. Votre nouveau fichier remplace le précédent.

## Dépannage

**L&#39;activité indique que vous devez être affecté à une équipe.** Vous ne faites pas encore partie d&#39;une équipe. Contactez votre instructeur.

**Vous ne pouvez pas passer à une autre instance.** Vous ne pouvez pas changer d’instance après la soumission de votre équipe. Le basculement est autorisé uniquement lorsque votre équipe est déverrouillée.

**L&#39;envoi a disparu et l&#39;état indique Envoi en attente.** Votre instructeur l’a annulé, et vous avez reçu une notification et un e-mail. Chargez à nouveau le fichier. Vous ne voyez pas le mémoire ou les commentaires précédents.
