# Création et publication d’un jeu de rôle d’entraîneur virtuel

Créez un scénario de jeu de rôle dans Adobe Learning Manager Virtual Coach afin que les élèves puissent s’entraîner à avoir des conversations en situation réelle dans le cadre d’un cours ou d’une assistance à la tâche. Cet article explique le processus complet de création d’un jeu de rôle Virtual Coach, du choix d’un modèle à la publication dans la bibliothèque de contenu.

Avant de commencer, vérifiez que Adobe Learning Manager Virtual Coach est activé sur votre compte et que vous êtes connecté en tant qu’auteur. Virtual Coach crée chaque jeu de rôle à partir des matériaux et des informations d’invite que vous fournissez. Il n’intègre pas automatiquement le contenu de cours existant de votre organisation. Si ce n&#39;est pas déjà fait, [rassemblez des matériaux pour un jeu de rôle d&#39;entraîneur virtuel](/help/migrated/authors/feature-summary/virtual-coach/gather-materials-for-virtual-coach-role-play.md) avant de commencer.

Pour créer un scénario de jeu de rôle IA dans Virtual Coach :
1. Dans le panneau de navigation de gauche, sélectionnez **Virtual Coach**, puis **Créer maintenant**.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach1.png)

2. Dans la section **En vedette**, choisissez un modèle **à une seule personne** ou **à plusieurs personnes**. Dans cet exemple, nous supposons que ce jeu de rôle est basé sur une seule personne. Pour les étapes impliquant plusieurs personnes, voir [jeu de rôle à plusieurs personnes](#configure-a-multi-persona-role-play)

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach2.png)

   La fenêtre **Créer un jeu de rôle** s&#39;ouvre.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach14.png)

3. Chargez éventuellement le matériau source, puis sélectionnez **Co-créer avec AI**.
4. Configurez les sujets de personnage, d’ouverture de conversation et d’évaluation.
5. Sélectionnez **Modifier** dans la section **Rubriques à couvrir**. Définissez les pondérations de score et les rubriques **décisives**.
6. Chacune des sections peut être modifiée de cette façon.
7. Si le contenu vous convient, sélectionnez **Approuver le contenu et continuer**.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach16.png)

8. Prévisualisez le jeu de rôle, puis **Publish**.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)

## Ouvrez Virtual Coach et commencez un jeu de rôle

Il existe deux façons de créer un jeu de rôle de Coach virtuel : commencer à partir d&#39;un modèle ou en créer un à partir de zéro avec l&#39;Assistant de co-création d&#39;IA. Cette section couvre la construction à partir de zéro.

1. Se connecter à Adobe Learning Manager en tant qu’auteur.
2. Sélectionnez **Virtual Coach** dans le volet de navigation de gauche.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach1.png)
   *Sélectionnez Virtual Coach sous Créer dans le volet de navigation de gauche pour commencer à créer un jeu de rôle.*

3. Sur la page **Virtual Coach**, sélectionnez **Créer maintenant**.
4. Sélectionnez un modèle dans la section **En vedette** ou la section **Modèles disponibles**. Les modèles proposés incluent deux options pour créer à partir de zéro :
   - **Jeu de rôle à une seule personne (assistant IA)** : l’élève interagit avec un personnage IA. Utilisez-le pour une conversation avec un client, une discussion sur le leadership, un appel à la découverte ou une conversation de coaching.
   - **Jeu de rôle multi-personnes (Beta)** : l’élève interagit avec jusqu’à quatre personnages IA dans la même conversation. Utilisez cette option pour une révision par un comité exécutif, un comité d’achat, un comité financier et juridique ou une négociation client impliquant plusieurs parties prenantes. Par exemple, un scénario de préparation au lancement de produit dans lequel un représentant doit présenter une nouvelle offre à un directeur financier, un responsable des achats, un Director informatique et un champion de l’utilisateur final en une seule session.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach2.png)
   *Choisissez un jeu de rôle à une seule personne ou à plusieurs personnes dans la section En vedette pour créer un scénario à partir de zéro, ou sélectionnez un modèle prédéfini ci-dessous.*

   Pour cet exemple, sélectionnez **Jeu de rôle personnel unique (Assistant IA)** dans la section **En vedette**. Pour commencer avec un scénario prêt à l&#39;emploi, consultez [Créer un jeu de rôle à l&#39;aide d&#39;un modèle Virtual Coach](/help/migrated/authors/feature-summary/virtual-coach/create-role-play-using-virtual-coach-template.md).
5. Vous pouvez également sélectionner **Charger des fichiers** pour ajouter des documents d&#39;accompagnement, tels qu&#39;une fiche produit, un playbook ou un enregistrement d&#39;appel. L’assistant de co-création d’IA les utilise pour créer un scénario plus précis. Ignorez cette étape si vous ne disposez pas de fichiers pertinents.
6. Sélectionnez **Co-Créer Avec AI**. Lorsque le message de confirmation apparaît, sélectionnez **Générer**.
7. Saisissez une description pour votre jeu de rôle. Utilisez une description qui décrit le scénario, telle que `Handling price objections in enterprise sales` ou `Pitching our new product to a buying committee`.
8. Poursuivez la conversation avec l’assistant d’IA, en ajoutant du contexte sur le scénario. L&#39;assistant explique qu&#39;un jeu de rôle comporte trois composants principaux : **Présentation** (titre et contexte de conversation), **Personnalité de l&#39;IA** (nom, organisation, rôle, arrière-plan, préoccupations, etc.) et **Rubriques d&#39;évaluation** (critères utilisés pour noter les élèves). Il vous demande si vous souhaitez élaborer ces éléments étape par étape ou les générer tous en même temps.
9. Continuez à ajouter des informations ou sélectionnez **Approuver le contenu et continuer** lorsque vous êtes satisfait.

## Configuration des paramètres de jeu de rôle

Après avoir créé un jeu de rôle Virtual Coach à l&#39;aide de l&#39;Assistant de co-création d&#39;IA, l&#39;écran **Modifier le jeu de rôle** s&#39;ouvre. Votre progression est enregistrée automatiquement, comme l&#39;indique l&#39;indicateur **Enregistré** dans le coin supérieur droit. Vous pouvez quitter cet écran et y revenir à tout moment sans perdre votre travail.

À partir de cet écran, vous avez trois options :

- **L&#39;aperçu** exécute une session de test en direct afin que vous puissiez expérimenter le jeu de rôle en tant qu&#39;élève avant quiconque. Utilisez cette option pour vérifier que le personnage semble naturel et que les rubriques s’enchaînent correctement.
- **Enregistrer** enregistre l&#39;état actuel sans publication. Le jeu de rôle est ajouté à la section **Modèles disponibles** de votre bibliothèque Virtual Coach, où vous pouvez revenir pour le modifier ultérieurement.
- **Publish** ajoute le jeu de rôle à la **bibliothèque de contenu** afin qu&#39;il puisse être affecté à un cours ou à une assistance à la tâche.

Pour apporter des modifications au contenu généré sans modifier les champs manuellement, sélectionnez **Modifier avec l&#39;IA** sur la droite. Cela ouvre l’interface de conversation IA et vous permet de décrire les modifications que vous souhaitez en langage clair, par exemple, `make the persona more formal` ou `add a topic about pricing objections`.

>[!NOTE]
>
>Cette opération est différente de l’édition par section. L’option d’édition par section vous donne accès à toutes les sections en même temps. L&#39;interface de chat de l&#39;IA, d&#39;autre part, vous donne une option pour décrire librement ce que vous voulez changer.

Sélectionnez **Modifier** en regard de **Titre du jeu de rôle** pour modifier le titre.

## Personnalisation de la simulation de votre Virtual Coach

Définissez le contexte de la conversation, le contexte de la personne et les préoccupations de la personne pour rendre votre scénario de jeu de rôle réaliste et stimulant. Plus vous fournissez de détails dans chaque champ, plus le personnage IA se comporte de manière précise et cohérente pendant la simulation.

Si vous avez utilisé **Co-créer avec l&#39;IA** ou **Générer automatiquement le jeu de rôle**, ces champs sont préremplis en fonction de vos entrées. Révisez-les et affinez-les avant de les publier.

### Contexte de conversation

Le champ **Contexte de conversation** définit le contexte pour l&#39;élève. Il indique au personnage de l&#39;IA l&#39;arrière-plan et le but du jeu de rôle afin que le personnage comprenne pourquoi la conversation a lieu et sur quoi devrait porter l&#39;attention principale.

>[!NOTE]
>
>Ce champ est écrit pour le persona IA, pas pour l’élève. N’incluez pas d’instructions ou de directives destinées à l’élève ici. Utilisez le champ **Ouvreur de formateur IA**, décrit plus loin dans cet article, pour un contexte orienté élève.

Lors de la rédaction du contexte de conversation :

- **Expliquez la situation.** Décrivez le type de conversation (appel de découverte commerciale, appel à froid ou argumentaire d’ascenseur) et l’initiateur.
- **Décrivez la position du personnage IA.** Expliquez qui est le personnage par rapport à l’élève. Par exemple, un client évaluant un produit, un directeur financier examinant une proposition de budget ou un employé recevant des commentaires.
- **Utilisez « l’élève » de manière cohérente.** Lorsque vous vous référez à la personne avec laquelle la personne parle, écrivez toujours « l’élève ». Évitez les étiquettes telles que « l&#39;agent », « le vendeur » ou « le représentant », qui peuvent entraîner un comportement incohérent de la personne.
- **Soyez concis.** Inclure uniquement les informations relatives à la configuration de la conversation. Enregistrez les détails spécifiques au personnage pour **Informations sur l&#39;arrière-plan personnel**.

**Exemple :** « Il s&#39;agit d&#39;un appel de découverte commerciale. L&#39;élève a contacté Karen Mitchell, du Medical Affairs Director d&#39;un réseau d&#39;hôpitaux de taille moyenne, pour planifier un appel d&#39;introduction. Karen a accepté un appel de 15 minutes pour en savoir plus sur la plateforme d’apprentissage. Elle est contrainte dans le temps et évalue si la plateforme répond aux normes de qualité du contenu clinique avant d&#39;impliquer son équipe. »

### Informations sur l’arrière-plan personnel

Le champ **Informations sur l&#39;arrière-plan de la personne** donne une personnalité à l&#39;IA. Plus vous entrez de détails, plus les réponses de la personne sont précises et cohérentes tout au long de la simulation.

Inclure :

- **Détails de base** : le nom, l&#39;âge, le rôle et la situation actuelle de la personne par rapport au sujet et à l&#39;objectif du jeu de rôle.
- **Motivations et objectifs** : ce qui intéresse la personne, ce qu&#39;elle veut réaliser ou changer, et les difficultés qu&#39;elle rencontre.
- **Croyances et attitudes** : comment le personnage se sent par rapport au sujet de la conversation et à l’organisation de l’élève.
- **Comportements et habitudes** : tendances qui façonnent la perspective de la personne, telles qu&#39;une prise de décision prudente ou un désir d&#39;adopter de nouveaux outils.
- **Critères de décision** : ce qui convainc la personne d’aller de l’avant, et les contraintes auxquelles elle est soumise, telles que le temps, le budget ou les processus d’approbation.

>[!TIP]
>
>Des détails spécifiques aident la personne à répondre d&#39;une manière naturelle et crédible. Les arrière-plans génériques produisent un comportement générique.

### Préoccupations personnelles

Les **préoccupations personnelles** définissent les problèmes, inquiétudes ou questions spécifiques que la personne soulève pendant la conversation. Ces préoccupations animent le flux du jeu de rôle et garantissent que l’élève doit répondre à des défis réalistes.

- **Énumérez trois à cinq préoccupations.** Exprimez-les tous en tant que préoccupations ou questions, et définissez-les de manière précise et pratique. Évitez les préoccupations vagues comme « inquiet au sujet des coûts »; écrivez « préoccupé par le fait que le coût annuel des licences dépassera le budget discrétionnaire du ministère sans l&#39;approbation du DPF ».
- **Concentrez-vous sur un seul sujet.** Une préoccupation par problème permet de gérer la conversation et de s’assurer que chaque défi est clairement évalué.
- **Indiquez quand le problème survient.** Indiquez le point de la conversation où le personnage le soulève.
- **Définissez ce qui est suffisant pour continuer.** Décrivez ce qui permettrait à la conversation d&#39;avancer. Par exemple, l’élève rassure le buyer persona, fournit une référence ou propose de la documentation.

Écrivez chaque problème à l’aide de cette structure : **→ de préoccupations lorsqu’il s’agit → ce qui est suffisant pour aller de l’avant.**

**Exemple :** « Préoccupation — Précision du contenu clinique : apparaît lorsque l’élève décrit le processus de création de contenu. Bonne pratique : l’élève déclare explicitement que le contenu est rédigé par des professionnels de la santé, examiné par des pairs et lié à la littérature primaire ou aux lignes directrices cliniques reconnues.

Une fois que vous avez renseigné les informations pertinentes, sélectionnez **Enregistrer**.

>[!TIP]
>
>Testez la durée de préoccupation avec **Aperçu**. Une préoccupation qui apparaît trop tôt ou trop tard perturbe le déroulement de la conversation.

>[!NOTE]
>
>Les modifications apportées aux paramètres de persona prennent effet immédiatement pour tout jeu de rôle non publié. Si vous modifiez un jeu de rôles déjà publié et attribué aux élèves, republiez-le pour appliquer le personnage mis à jour aux sessions futures.

## Configuration d’une présentation pour votre simulation

Utilisez la section **Paramètres de présentation** pour joindre un jeu de diapositives à votre simulation de jeu de rôle. Lorsqu’une présentation est jointe, les élèves peuvent la consulter pendant la session en tant que référence ou aide à la conversation. Par exemple, une présentation de produit utilisée lors d’une simulation de argumentaire de vente.

1. Sélectionnez **Télécharger le PDF ou PPTX** sous **Détails de la présentation**.
2. Sélectionnez votre fichier. Les formats PDF et PPTX sont pris en charge, avec une taille de fichier maximale de 100 Mo.
3. Une fois téléchargé, le nom du fichier apparaît sous le bouton, confirmant la pièce jointe.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach3.png)
   *Joignez une présentation afin que les élèves puissent la référencer comme aide à la parole pendant leur simulation.*

4. Sélectionnez **Terminé** pour enregistrer le paramètre et revenir à la configuration du jeu de rôle.

Une fois que vous avez chargé une présentation, l&#39;option **Autoriser les élèves à charger leur propre présentation** s&#39;active automatiquement. Vous pouvez également télécharger ou supprimer le fichier joint à l’aide des boutons situés à droite.

Sélectionnez **Autoriser les élèves à télécharger leur propre présentation** si vous souhaitez que chaque élève s&#39;entraîne avec sa propre version d&#39;un jeu de diapositives plutôt qu&#39;avec une présentation partagée. Cela se révèle utile lorsque les élèves sont évalués sur la base d&#39;une présentation qu&#39;ils ont préparée personnellement, telle qu&#39;une analyse commerciale ou un argumentaire de vente personnalisé. Cette option est désactivée par défaut. Lorsque cette option est activée, les élèves voient une invite de téléchargement au début de leur session.

>[!NOTE]
>
>Assurez-vous que toutes les présentations que vous téléchargez sont accessibles. Utilisez un contraste de couleur suffisant, incluez du texte optionnel pour les images et évitez le contenu qui ne repose que sur la couleur pour donner du sens.

## Configuration du personnage IA

La section **Configuration de la personnalité par l’IA** contrôle avec qui l’élève parle pendant la simulation, ainsi que son apparence, sa voix, son rôle et sa personnalité comportementale. L&#39;une des étapes les plus importantes de la création d&#39;un scénario de jeu de rôle de l&#39;IA consiste à trouver la bonne section, car un personnage d&#39;avatar bien configuré rend le jeu de rôle réaliste et garantit que l&#39;IA se comporte de manière cohérente avec le scénario que vous avez conçu.

### Choisir un persona

Deux onglets sont disponibles : **Personnages système** et **Personnages personnalisés**.

Les **personnages système** sont des caractères préconfigurés fournis par Adobe. Chacun d&#39;eux a un nom, une photo et un ou deux modes d&#39;interaction pris en charge : **Voix et vidéo** (le personnage apparaît sous la forme d&#39;un avatar animé avec une voix parlée) ou **Voix** (voix parlée uniquement, sans avatar vidéo). Sélectionnez un personnage système en sélectionnant sa vignette.

Les **personnalités personnalisées** sont des personnalités que vous avez créées précédemment. Sélectionnez cet onglet pour réutiliser un personnage d&#39;avatar IA d&#39;un jeu de rôle précédent au lieu d&#39;en créer un à partir de zéro.

![](/help/migrated/authors/feature-summary/assets/virtual_coach4.png)
*Réutilisez un personnage personnalisé d’un jeu de rôle précédent au lieu d’en créer un nouveau à partir de zéro.*

Vous pouvez réutiliser un personnage de deux manières : modifier ses détails directement pour le transformer en un personnage différent ou sélectionner **Dupliquer** pour créer une copie et modifier les détails de la copie. Pour afficher les deux options, sélectionnez l’icône de points de suspension verticaux (**⋮**) qui apparaît dans le coin supérieur droit de l’image d’un personnage lorsque vous le survolez ou le sélectionnez.

### Configuration des détails et de la personnalité

Après avoir sélectionné un persona, renseignez les champs **Détails de la personne IA** :

1. Entrez le **rôle** de la personne : son titre de poste tel qu&#39;il doit apparaître dans la simulation, par exemple, Medical Affairs Director.
2. Entrez l&#39;**organisation** de la personne : la société ou l&#39;institution pour laquelle elle travaille. Par exemple, Northgate Health.
3. Sélectionnez une **personnalité** qui correspond au niveau de défi et au contexte du scénario :

   | Personnalité | Comportement |
   |---|---|
   | Sceptique | Remet tout en question et exige une preuve |
   | Indifférent | Désengagé et difficile à exciter |
   | Enthousiaste | Enthousiasmé par la solution et prêt à s’engager |
   | Orienté relation | Les valeurs sont avant tout la confiance et le lien personnel |
   | Neutre | Reste équilibré et évalue les options sans biais |
   | Affirmé | Contondante, rapide, et a tendance à défier les autres |

4. Activez éventuellement **Autoriser les élèves à sélectionner cette option avant le début du jeu de rôle** pour permettre aux élèves de choisir la personnalité du personnage avant de lancer la session. Ceci est utile pour les scénarios en mode pratique où les élèves veulent contrôler la difficulté.
5. Sélectionnez **Terminé** pour enregistrer la configuration du persona.

>[!TIP]
>
>Adaptez la personnalité au défi du scénario. Un scénario d&#39;appel à froid bénéficie d&#39;un personnage **sceptique** ou **indifférent** pour simuler une perspective difficile. Un scénario de retour d&#39;informations sur le leadership fonctionne bien avec une approche **affirmée** ou **orientée vers la relation** pour refléter une dynamique gestionnaire-employé réaliste.

### Création d’un personnage personnalisé

Si les personas système ne correspondent pas à votre scénario, créez-en un nouveau à partir de l&#39;onglet **Personnages personnalisés**.

1. Sélectionnez **Personnalités personnalisées**, puis **Créer une personne**.
2. Chargez une photo pour le personnage. L’image doit faire au moins 640 x 360 pixels et ne pas dépasser 1 Mo.
3. Saisissez le **prénom** du personnage.
4. Sélectionnez une **voix** dans le menu déroulant pour définir la voix de l&#39;IA.
5. Réglez le curseur **Débit vocal** pour contrôler la vitesse d&#39;élocution, de -100 (le plus lent) à +100 (le plus rapide). La valeur par défaut est 0 (espace neutre). Sélectionnez **Tester la voix** pour prévisualiser le son de la voix avant d&#39;enregistrer.
6. Sélectionnez **Créer un persona**. Le nouveau personnage est enregistré dans votre onglet **Personnages personnalisés** et peut être utilisé dans tout jeu de rôle futur.

>[!NOTE]
>
>Les personas personnalisés prennent en charge l’interaction vocale. Confirmez que le taux de voix semble naturel pour le scénario avant de publier : un taux très rapide ou très lent peut rendre la simulation peu naturelle et affecter le score de rythme de l&#39;élève.

L&#39;activation de l&#39;**avatar vidéo** ajoute un avatar vidéo IA photoréaliste au jeu de rôle. Les avatars vidéo sont disponibles pour les personas qui prennent en charge le mode **Voix et vidéo**. Chaque élève dispose de 300 minutes de jeu de rôle vidéo par mois ; une fois cette limite atteinte, l’expérience se transforme en avatar statique.

### Configuration d’un jeu de rôles à plusieurs personnes

Utilisez un jeu de rôles à plusieurs personnes lorsque l’élève doit parcourir une conversation impliquant plusieurs parties prenantes dans la même session. Par exemple, présenter un nouveau produit à un comité d’achat composé d’un directeur financier, d’un responsable des achats, d’un Director informatique et d’un champion de l’utilisateur final. Les jeux de rôle multi-personnages prennent en charge **jusqu&#39;à quatre personnages** dans un seul scénario.

1. Sélectionnez **Jeu de rôle multi-personnes** comme modèle lorsque vous démarrez le jeu de rôle.
2. Ajoutez chaque personnage et attribuez-lui un rôle distinct. Par exemple, CFO, Procurement Manager, IT Director et Champion.
3. Configurez une personnalité distincte pour chaque personnage, en suivant les mêmes étapes **Détails de la personne IA** décrites ci-dessus.
4. Définissez des préoccupations uniques pour chaque persona, en utilisant la même structure de préoccupations décrite dans **Préoccupations personnelles**. Chaque personnage pose des questions et soulève des objections de sa propre perspective, de sorte que l&#39;élève doit adapter son message pour chaque partie prenante à tour de rôle plutôt que de donner un discours générique.

## Configurer l&#39;ouverture de la conversation

La section **Ouverture de la conversation** contrôle les deux premières choses qu&#39;un élève entend lorsqu&#39;une simulation commence : une brève déclaration contextuelle du formateur en IA, suivie de la ligne d&#39;ouverture du personnage IA.

![](/help/migrated/authors/feature-summary/assets/virtual_coach5.png)
*Le formateur en IA prépare le terrain en premier, puis le personnage IA ouvre la conversation en caractère.*

**L&#39;ouvreur d&#39;entraîneur IA** est un court message parlé par l&#39;entraîneur, pas par le personnage, avant le début de la conversation. Il indique à l&#39;élève à qui il va parler, quel est l&#39;objectif et le contexte pertinent dans lequel il doit s&#39;inscrire. Sélectionnez **Modifier** pour mettre à jour le texte. Soyez bref et direct. Pour les scénarios plus exigeants, inclure explicitement l&#39;objectif, par exemple : « Vous êtes sur le point de faire un appel à froid à un responsable principal de l&#39;approvisionnement. Votre objectif est d&#39;obtenir une réunion de suivi. »

**L’AI Persona Opener** est la première ligne que l’AI persona envoie à l’élève, pour commencer la conversation. Il doit refléter la personnalité du personnage et mettre l&#39;élève sur la sellette dès le premier exchange. Sélectionnez **Modifier** pour mettre à jour le texte.

| Scénario | Exemple d’ouvreur |
|---|---|
| Appel à froid | « Allô ? Qui est-ce ? » |
| Appel de découverte planifié | « Bonjour, merci d&#39;avoir tendu la main. Qu&#39;est-ce que vous vouliez couvrir aujourd&#39;hui ? » |
| Conversation de commentaires | « Vous avez une minute ? Je voulais parler de la semaine dernière. » |
| Présentation exécutive | « Je n&#39;ai que dix minutes. Qu&#39;est-ce que tu as pour moi ? » |

Sélectionnez **Aperçu** pour entendre les deux ouvertures lues dans l&#39;ordre, exactement comme l&#39;élève les verra au début d&#39;une session.

>[!TIP]
>
>Si les tonalités des dispositifs d&#39;ouverture d&#39;entraîneur IA et d&#39;ouverture de personne IA sont trop similaires, la transition entre elles peut être déroutante. Gardez l&#39;ouvre-personne neutre et instructif ; laissez l&#39;ouvre-personne porter la personnalité.

## Configuration des rubriques et des critères d’évaluation

La section **Rubriques à couvrir** définit ce que l&#39;élève doit aborder pendant la simulation et comment l&#39;IA évalue ses performances sur chaque sujet : il s&#39;agit de votre rubrique de notation du jeu de rôle de l&#39;IA. Chaque rubrique que vous ajoutez devient un composant noté dans le rapport de connaissances de l’élève.

**Avant de commencer :** complétez d&#39;abord la section **Personnaliser votre simulation**. L&#39;IA utilise votre contexte de conversation et votre arrière-plan personnel pour générer des directives d&#39;évaluation précises pour chaque sujet.

Chaque ligne du tableau des rubriques représente un domaine de conversation requis :

| Colonne | Objectif |
|---|---|
| Rubrique | Nom de la zone de conversation que l’élève doit couvrir |
| Directives d’évaluation | Critères utilisés par l’IA pour évaluer si le sujet a été traité de manière adéquate ; ces directives apparaissent également sous forme de commentaires sur la page d’analyse de l’élève |
| Épaisseur | Pourcentage de la note de connaissances attribuée à ce sujet ; toutes les pondérations de sujets doivent totaliser 100 % |
| Exemple de vidéo | Vidéo facultative que l’élève peut regarder sur sa page d’analyse pour voir comment le sujet doit être traité. |
| Lien utile | URL facultative affichée sur la page d’analyse de l’élève en regard des critères d’évaluation |
| Créer ou interrompre | Lorsque cette option est activée, si l’élève ne traite pas ce sujet du tout, le score final de la simulation est de 0, indépendamment des performances sur les autres sujets |

![](/help/migrated/authors/feature-summary/assets/virtual_coach6.png)
*Chaque ligne de rubrique définit ce qu&#39;il faut évaluer, sa valeur et s&#39;il est nécessaire de la passer.*

### Ajouter une rubrique

1. Sélectionnez **Modifier** dans la section **Rubriques à couvrir** pour ouvrir le tableau des rubriques.
2. Sélectionnez **Ajouter une rubrique**. Une nouvelle ligne s’affiche avec des champs vides.
3. Entrez le nom de la rubrique dans le champ **Rubrique**. Utilisez un libellé court et descriptif qui reflète la zone de conversation, par exemple `Opening and Rapport`, `Handling Objections` ou `Agreeing Next Steps`.
4. Saisissez les directives d&#39;évaluation dans le champ **Directives d&#39;évaluation**. Rédigez-les sous la forme d’une déclaration d’achèvement en commençant par « Pour couvrir ce sujet avec succès, l’élève doit... ».
5. Entrez un pourcentage dans le champ **Poids**. Répartissez les pondérations sur toutes les rubriques afin que le total soit égal à 100 %.
6. Vous pouvez également sélectionner **Cliquer pour ajouter une vidéo** pour joindre un exemple de vidéo ou **Cliquer pour ajouter une URL** pour joindre un lien utile, tel qu&#39;un article de la base de connaissances ou un document d&#39;une page produit.
7. Activez éventuellement **Marquer ou interrompre** pour les rubriques non négociables.
8. Répétez l&#39;opération pour chaque rubrique à inclure, puis sélectionnez **Terminé**.

### Modification ou suppression d’une rubrique

- Pour modifier n’importe quel champ d’une ligne de rubrique existante, sélectionnez le champ directement et mettez à jour le texte ou la valeur.
- Pour régénérer les directives d&#39;évaluation à l&#39;aide de l&#39;IA en fonction de votre personnage et de votre contexte, sélectionnez l&#39;icône d&#39;actualisation (**↻**) dans la cellule **Directives d&#39;évaluation**.
- Pour supprimer une rubrique, sélectionnez le menu Options (**⋮**) à la fin de la ligne et sélectionnez **Supprimer la rubrique**.
- Pour dupliquer une rubrique et l&#39;utiliser comme base pour une rubrique similaire, sélectionnez **Dupliquer la rubrique** dans le même menu.

### Conseils pour la rédaction de rubriques efficaces

Une grille de score de jeu de rôle forte de l&#39;IA fait la différence entre un jeu de rôle qui semble juste et un jeu de rôle qui semble arbitraire. Gardez ces recommandations à l’esprit :

- **Nommez les sujets après les étapes de la conversation, et non les fonctionnalités du produit.** Les rubriques telles que `Opening and Rapport`, `Needs Discovery` et `Agreeing Next Steps` reflètent la structure d’une vraie conversation.
- **Rédigez des directives d&#39;évaluation sous forme d&#39;actions observables.** L&#39;IA évalue ce que l&#39;élève a dit, de sorte que les lignes directrices doivent décrire des comportements spécifiques audibles, et non des intentions. Comparez « l’élève doit comprendre les préoccupations de la personne » (faible) avec « l’élève doit lui demander de nommer sa principale préoccupation et confirmer qu’il l’a entendue avant de répondre » (forte).
- **Utilisez l’option Créer ou interrompre avec parcimonie.** Réservez-le pour un ou deux sujets où l&#39;omission totale ferait clairement de la conversation un échec, comme le fait de ne pas se présenter lors d&#39;un appel à froid. L’appliquer à trop de sujets complique la tâche des élèves, même pour une tentative raisonnable.
- **Équilibrez les poids pour refléter l&#39;importance de la conversation.** Un sujet qui occupe la plus grande partie d&#39;une conversation typique, comme la découverte des besoins dans un appel de vente, doit avoir plus de poids qu&#39;un bref ouverture ou fermeture.
- **Ajoutez des liens utiles vers les sujets à faible score.** Si les élèves obtiennent systématiquement de mauvais résultats sur un sujet particulier d’une session à l’autre, joignez un lien de ressource afin d’avoir quelque chose à étudier entre les tentatives.

## Configuration des paramètres de langue

La section **Paramètres de langue** contrôle si les élèves peuvent choisir la langue dans laquelle ils s&#39;entraînent lorsqu&#39;ils lancent la simulation. Activez **Autoriser les élèves à choisir leur langue d&#39;exercice** pour permettre à chaque élève de sélectionner sa langue préférée au début de la session. Laissez cette option désactivée si vous souhaitez que tous les élèves s’entraînent dans la langue dans laquelle le jeu de rôles a été créé - paramètre recommandé pour les évaluations formelles où la cohérence linguistique fait partie des critères d’évaluation.

>[!NOTE]
>
>Virtual Coach prend en charge le contenu de simulation dans neuf langues. La sélection de la langue de l&#39;élève n&#39;a de sens que si le contenu du scénario et votre personnage sont écrits pour prendre en charge une utilisation multilingue ; si vos directives d&#39;évaluation et votre arrière-plan de personnage sont écrits dans une seule langue, l&#39;activation de ce paramètre peut produire des réponses d&#39;IA incohérentes pour les élèves qui sélectionnent une langue différente.

## Configuration de l’analyse des actions à l’écran

La section **Analyse des actions à l&#39;écran** vous permet de charger une vidéo des meilleures pratiques qui montre à l&#39;IA comment évaluer les actions entreprises par un élève pendant le jeu de rôle. Cette fonction est particulièrement utile pour les simulations où l’élève est censé démontrer des actions spécifiques de manière visible à l’écran, telles que la navigation dans une interface logicielle, le remplissage d’un formulaire ou le suivi d’un processus défini étape par étape.

>[!NOTE]
>
>Cette option est désactivée si vous n&#39;avez chargé que des fichiers PowerPoint ou PDF dans la section **Paramètres de présentation**.

1. Sélectionnez **Sélectionner un fichier** pour ouvrir l&#39;explorateur de fichiers.
2. Sélectionnez votre fichier vidéo et confirmez le téléchargement.
3. Une fois téléchargé, le nom du fichier apparaît dans la ligne de résumé **Analyse des actions à l&#39;écran**.

Votre vidéo doit répondre aux exigences suivantes :

| Exigence | Spécification |
|---|---|
| Format du fichier | WEBM, MP4, WMV ou MPEG |
| Taille de fichier maximale | 200 Mo |
| Résolution minimale | 1280 x 720 pixels |
| Tarif cadre minimum | 5 I/S |
| Format | Entre 4:3 et 21:9 |

Lors de l’enregistrement d’une vidéo conforme aux bonnes pratiques, décrivez chaque action à la fois dans la piste audio et à l’écran. Par exemple, « Je sélectionne maintenant le bouton Envoyer » ce faisant, car l’IA repose à la fois sur la narration et sur l’action visuelle. Concentrez l’enregistrement sur la tâche, supprimez les notifications et le contenu sans lien, et faites correspondre la vidéo à vos directives d’évaluation afin qu’elle démontre chaque action requise au point du workflow où elle est attendue.

## Configuration des paramètres de score

**Note de réussite** est le score global minimum qu&#39;un élève doit obtenir pour que la simulation soit marquée comme réussie, appliqué à la combinaison pondérée des notes de connaissance et de style. Entrez un nombre compris entre 1 et 100 dans le champ **Note de réussite** (la valeur par défaut est 80), puis sélectionnez **Terminé**.

>[!TIP]
>
>Pour les évaluations formelles, un score de réussite de 75 à 80 est typique. Pour les jeux de rôle en mode pratique dont l&#39;objectif est le développement des compétences plutôt que la certification, envisagez un seuil inférieur ou activez le **mode pratique**.

**Les pondérations de score de l’IA** définissent la contribution du composant Connaissances (si l’élève a couvert les sujets requis et donné des informations précises) et du composant Style (rythme, clarté, mots de remplissage, longueur de phrase, énergie) au score global. Faites glisser le curseur pour régler la balance. Les deux valeurs totalisent toujours 100 %, et la valeur par défaut est Connaissance 70 % / Style 30 %. Pour obtenir des conseils sur la façon dont les élèves interprètent ces scores, consultez [Comprendre votre rapport de performance d&#39;entraîneur virtuel](/help/migrated/learners/feature-summary/virtual-coach/understand-virtual-coach-performance-report.md).

| Type de scénario | Rapport recommandé | Cause |
|---|---|---|
| Évaluation des compétences ou certification | 80 % de connaissances / 20 % de style | La précision du contenu est la mesure principale |
| Activation des ventes | 60 % de connaissances / 40 % de style | La livraison est aussi importante que le message dans les conversations avec le client |
| Développement du leadership | 70 % de connaissances / 30 % de style | Équilibré : le contenu et le ton sont essentiels dans les conversations entre les personnes |
| Coaching en communication | 40 % de connaissances / 60 % de style | Le style est le principal objectif d’apprentissage |

**Activer le mode d&#39;entraînement pour les élèves** permet aux élèves de demander des conseils pendant la simulation pour les aider à rester sur la bonne voie, ce qui est utile pour l&#39;apprentissage en début de carrière. Lorsque cette option est activée, vous pouvez définir **Nombre maximum de conseils par session** (5 par défaut, réglable de 1 à 10) et la durée de visibilité des conseils (30 secondes par défaut).

>[!NOTE]
>
>Les conseils ne sont pas disponibles lors des évaluations formelles. Si vous utilisez ce jeu de rôles comme évaluation notée, désactivez le mode Exercice pour que tous les élèves soient évalués dans les mêmes conditions.

**Masquer le score** empêche les élèves de voir leur score numérique après la session ; ils reçoivent toujours un retour d&#39;informations qualitatif et une analyse au niveau du sujet. Utilisez cette option lorsque le jeu de rôle est uniquement destiné à la pratique, lorsque seul un évaluateur de responsable doit voir le résultat ou lorsque vous souhaitez réduire l’anxiété liée aux scores lors des premiers stades d’apprentissage.

## Configuration des paramètres avancés de jeu de rôle

Ces paramètres facultatifs contrôlent comment et quand la simulation se termine et comment l&#39;environnement de session est configuré.

**Autorisez l&#39;IA à mettre fin au jeu de rôle.** Par défaut, seul l&#39;élève peut terminer une simulation en sélectionnant **Terminer la simulation**. Activez cette option et décrivez la condition sous laquelle le persona doit fermer la conversation naturellement, par exemple : « Lorsque l’élève planifie avec succès une réunion de suivi ou que le persona refuse trois fois, le persona doit terminer l’appel poliment. » Utilisez cette option pour les scénarios avancés où le point de terminaison naturel de la conversation, et non un minuteur, doit déterminer la fermeture de la session.

**Limite de temps de simulation.** Entrez un nombre compris entre 1 et 59 minutes pour définir une durée maximale de session. Une fois cette durée atteinte, la simulation se termine automatiquement et l&#39;élève est redirigé vers la page d&#39;analyse.

| Type de scénario | Limite suggérée |
|---|---|
| Appel à froid ou bref exercice d’ouverture | 3-5 minutes |
| Appel de découverte ou évaluation des besoins | 10-15 minutes |
| Conversation commerciale complète ou discussion sur le leadership | 15-20 minutes |
| Évaluation formelle avec plusieurs rubriques | Correspond à la durée de conversation réelle attendue |

La **pénalité de session courte** décourage les élèves de mettre fin aux sessions trop rapidement en appliquant une réduction de score si la session tombe en dessous d&#39;une durée minimale que vous définissez. Utilisez cette option lorsque la durée de la session est significative pour l’objectif d’apprentissage. Par exemple, dans un appel de découverte où l’élève doit passer suffisamment de temps à découvrir les besoins avant de proposer une solution.

>[!NOTE]
>
>N&#39;utilisez pas la pénalité de session courte dans les jeux de rôle en mode pratique où les élèves sont encore en train de gagner en confiance, car pénaliser les sorties précoces peut augmenter l&#39;anxiété et décourager les tentatives répétées.

**Activer le partage d&#39;écran** permet aux élèves de partager leur écran pendant la simulation. Ceci est pertinent pour les scénarios qui incluent un composant **Analyse d&#39;action à l&#39;écran**. Il est désactivé par défaut si vous n&#39;avez chargé que des documents PowerPoint ou PDF dans **Paramètres de présentation**.

**Activer les sous-titres du personnage IA** affiche à l&#39;écran le texte de ce personnage IA en temps réel. Activez cette option pour les élèves ayant des difficultés auditives ou pratiquant dans une deuxième langue, dans des environnements bruyants ou dans des scénarios où la lecture des mots exacts de la personne est importante pour comprendre des objections nuancées.

2. Sélectionnez le dossier dans lequel vous souhaitez ajouter le jeu de rôle.
3. Ajoutez éventuellement des balises et une date d’expiration.
4. Sélectionnez **Enregistrer**. Le jeu de rôle est ajouté à la **bibliothèque de contenu**.
