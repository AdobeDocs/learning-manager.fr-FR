# Définir le mode clair ou le mode sombre pour le cours

<!--Select **light/dark** mode in the toolbar to toggle between modes. Content Composer updates the canvas to reflect the selected mode.-->

Sélectionnez le [!UICONTROL menu Compte] > [!UICONTROL Appliquer le thème] > mode clair ou sombre. Le compositeur de contenu met à jour la zone de travail pour refléter le mode sélectionné.
