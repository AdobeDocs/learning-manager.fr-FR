# Affichage et ajout de commentaires à un cours

Si vous êtes le créateur du cours, sélectionnez le panneau **Commentaires** dans votre projet pour afficher les commentaires et y répondre.

1. **Ouvrir le panneau Commentaires** : sélectionnez **Commentaires** dans la barre d&#39;outils. Le panneau des commentaires affiche les commentaires fournis par le réviseur.

2. Vous pouvez marquer les commentaires comme résolus ou les modifier ou les supprimer.

3. Apportez les modifications requises et **enregistrez** le projet.

4. Sélectionnez **Partager** dans la barre d&#39;outils pour mettre à jour le lien le plus récent.
