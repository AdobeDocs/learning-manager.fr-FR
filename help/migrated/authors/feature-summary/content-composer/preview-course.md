# Aperçu du cours

![](../assets/19_preview_mode_timeline_block_updated.png)

- Sélectionnez **Aperçu** dans la barre d&#39;outils supérieure. Le cours s’affiche exactement comme un élève le verra, avec le thème appliqué, les composants interactifs et le quiz en mode réponse.

- Naviguez à l&#39;aide des options **Suivant** et **Précédent** ou sélectionnez une rubrique dans le panneau de leçon sur la gauche. Sélectionnez **Quitter l&#39;aperçu** dans le coin supérieur droit pour revenir à la modification.
