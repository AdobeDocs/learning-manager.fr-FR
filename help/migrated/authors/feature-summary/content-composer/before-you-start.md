# Avant de commencer

Avant de lancer Adobe Learning Manager Content Composer, vérifiez les points suivants :

>[!IMPORTANT]
>
>Vous devez vous connecter avec un compte Adobe Creative Cloud valide. Si vous n’en avez pas encore, vous pouvez créer un compte gratuit via Adobe Express. Pour plus d&#39;informations, consultez [Créer un compte gratuit Adobe Express](https://helpx.adobe.com/fr/express/web/adobe-express-subscription/free.html). Après avoir créé vos informations d’identification d’Adobe, lancez le compositeur de contenu et connectez-vous pour commencer à créer des cours. Si votre organisation dispose déjà d’un abonnement de Creative Cloud, contactez votre administrateur pour provisionner un compte de Creative Cloud pour vous avant de vous connecter au compositeur de contenu.

Pour une expérience optimale avec Content Composer, **Google Chrome est le navigateur recommandé**. Firefox et Safari peuvent présenter des différences de fonctionnalité ou de comportement.

## Menu Compte et préférences dans le compositeur de contenu

Accédez aux paramètres de votre compte Adobe, définissez vos préférences d’affichage et ouvrez les projets récents à partir du menu du compte du compositeur de contenu.

La barre d’outils du compositeur de contenu inclut le menu du compte de navigation universel d’Adobe. Utilisez-le pour ajuster votre thème d’affichage et votre langue, et pour rouvrir rapidement les projets sur lesquels vous avez travaillé récemment.

### Ouvrir le menu du compte

Sélectionnez l’icône de profil dans le coin supérieur droit de la barre d’outils du compositeur de contenu pour ouvrir le menu du compte.

1. Définition de vos préférences
2. Sélectionnez l’icône de votre profil pour ouvrir le menu du compte.
3. Sélectionnez [!UICONTROL Préférences]. La boîte de dialogue [!UICONTROL Préférences] s&#39;ouvre.
4. Sous [!UICONTROL Thème], sélectionnez [!UICONTROL Clair] ou [!UICONTROL Foncé] pour définir le mode d&#39;affichage de l&#39;interface du compositeur de contenu.
5. Sous [!UICONTROL Langue], sélectionnez la langue d&#39;affichage de votre choix.
6. Sélectionnez [!UICONTROL Enregistrer] pour appliquer vos modifications.

>[!NOTE]
>
>Les préférences de thème et de langue s’appliquent uniquement à l’interface du compositeur de contenu. Ils n&#39;affectent pas le thème visuel de votre cours ni la langue de votre contenu de cours.

## Ouvrir un projet récent

Le menu Compte comprend une liste [!UICONTROL Récents] affichant vos derniers projets du compositeur de contenu ouverts.

Sélectionnez un projet dans la liste [!UICONTROL Récents] pour l&#39;ouvrir directement.

## Exigences facultatives

* Vous avez une idée générale du sujet que vous souhaitez couvrir. Vous n’avez pas besoin d’être parfaitement clair avant de commencer.

* L&#39;IA vous guide tout au long de la définition du titre du cours, du public visé et des objectifs d&#39;apprentissage par la conversation.

* Les documents sources sont facultatifs. Vous pouvez continuer sans télécharger de fichiers, et l’IA générera du contenu en fonction de vos entrées.

* Si vous disposez d&#39;un matériau existant, à partir duquel vous souhaitez que le cours dessine, vous pouvez le charger pendant l&#39;étape Brief. Les formats de fichiers pris en charge sont PDF, Markdown (.md), PowerPoint (.pptx) et autres, chacun jusqu’à 100 Mo.
