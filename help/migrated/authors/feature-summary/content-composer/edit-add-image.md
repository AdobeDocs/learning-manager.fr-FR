# Modifier ou ajouter une image

![](../assets/16_hierarchy_of_controls_eliminate_substitute_updated.png)

Sélectionnez une image pour ouvrir la barre d’outils d’image. Les contrôles comprennent :

- **Remplir**, **Adapter :** à la taille de l&#39;image dans son bloc

- Champ **Texte alternatif** : affiche la description de l&#39;image.<br>
  **Remarque** : ce texte ne peut pas être modifié. Il est mis à jour automatiquement en fonction de l’image.

- Icône **Plus d&#39;options** : **ajuste** la luminosité, la saturation et la transparence de l&#39;image.

Pour remplacer l&#39;image, sélectionnez l&#39;icône **image** pour la modifier. Choisissez de charger votre propre fichier, de rechercher dans Adobe Stock ou d’en générer un avec l’IA.
