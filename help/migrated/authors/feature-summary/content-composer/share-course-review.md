# Partage d’un cours pour révision

1. Sélectionnez **Pour révision**.

2. Saisissez les noms ou les adresses e-mail de vos réviseurs dans le champ Ajouter des noms ou des adresses e-mail.

3. Consultez la section **Qui a accès** pour confirmer que seules les personnes invitées peuvent accéder au projet.

4. Sélectionnez **Inviter à commenter** ou **Copier le lien** pour le partager avec vos réviseurs.
