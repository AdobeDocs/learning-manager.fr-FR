# Ce que n’est pas Adobe Learning Manager Content Composer

Pour définir des attentes précises avant de commencer :

- Le compositeur de contenu ne prend pas en charge l’embranchement ou les parcours d’apprentissage adaptatif. Les cours suivent une structure linéaire Leçons > Rubriques.

- Le quiz de fin de leçon prend uniquement en charge les questions à choix multiples et les questions Vrai/Faux dans la version Beta actuelle. D&#39;autres types de questions figurent sur la feuille de route.

## Étape suivante

Lorsque vous êtes prêt à commencer, consultez la section [Création d&#39;un cours avec le compositeur de contenu](#create-course) pour connaître le workflow complet étape par étape.

**Essayer l&#39;application**. Ouvrez le [**Compositeur de contenu**](https://contentcomposer.adobe.io/) et suivez les instructions étape par étape.

Si vous rencontrez des problèmes, contactez le support technique ou publiez vos questions sur la [communauté Adobe Learning Manager](https://community.adobe.com/adobe-learning-manager-466).
