# Partager un cours avec les élèves

1. Sélectionnez **Pour les élèves**.

2. Sélectionnez **Générer le lien** pour générer un lien permettant à l’élève d’accéder au projet.

3. Partagez le lien avec vos élèves.

>[!IMPORTANT]
>
>Chaque fois que vous mettez à jour le cours, les élèves peuvent utiliser le même lien pour afficher les modifications apportées au cours.
