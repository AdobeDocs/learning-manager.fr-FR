# Gérer le panneau Participants

Utilisez le panneau **Participants** pour afficher et gérer les participants à une session Live Hub. Le panneau affiche une liste en temps réel des participants, y compris les élèves qui ont rejoint la session et ceux inscrits mais qui ne l’ont pas encore fait. Elle affiche également le rôle et le statut d’interaction de chaque participant.

En tant qu’instructeur, vous pouvez utiliser le panneau Participants pour gérer la participation des élèves, configurer les autorisations des participants et modérer les interactions pendant la session. Vous pouvez effectuer des actions telles que couper le son des microphones, baisser les mains levées, envoyer des messages privés et supprimer des élèves de la session.

Cet article explique comment accéder au panneau Participants et gérer les élèves pendant une session Live Hub.

## Afficher le panneau Participants

Le panneau **Participants** affiche tous les participants à la session. Pour l&#39;ouvrir, sélectionnez ![open-attendees-panel](./assets/open-attendees.svg) dans la barre de contrôle. Le panneau répertorie automatiquement tous les élèves et les mises à jour lorsque les participants rejoignent ou quittent le programme.

![Présentation du panneau Participants](assets/attendees-panel-overview.png)
*Interface Live Hub affichant le panneau Participants.*

Les options suivantes sont disponibles dans le panneau :

| **Option** | **Description** |
|----|----|
| **Recherche** | Tapez le champ **Rechercher** pour trouver un participant. Filtres de liste au fur et à mesure de la saisie. |
| **Présent** | Affiche les élèves actuellement dans la session, ainsi que leurs rôles (par exemple, instructeur) et l’état du microphone. Le nombre entre parenthèses indique le nombre de caractères présents. |
| **Non inscrit** | Affiche les élèves inscrits à la session qui ne l&#39;ont pas encore rejoint. Sélectionnez la flèche pour développer la liste. |

## Paramètres du panneau Participants

Pour gérer les préférences des participants :

1. Sélectionnez **Autres options (⋯)** dans le panneau **Participants**.

1. Vous pouvez effectuer les actions disponibles suivantes :

   1. **Abaissez toutes les mains** : abaissez toutes les mains levées pour les participants.

   1. **Couper le son à tous les participants** : coupez le son des microphones de tous les participants.

   1. **Désactiver la caméra pour tous les participants** : désactivez les caméras de tous les participants.

## Gérer les élèves pendant la session

Le panneau **Participants** vous permet de gérer des élèves individuels pendant la session. Vous pouvez modérer les interactions et effectuer des actions rapides pour un élève spécifique si nécessaire, comme couper le son de son microphone, baisser une main levée, envoyer un message privé ou afficher son profil, pour vous aider à maintenir un environnement d&#39;apprentissage organisé.

Pour mettre à jour les autorisations des élèves :

1. Accédez à l’élève dans le panneau **Participants**.

1. Sélectionnez l&#39;icône **Plus d&#39;options (⋯)** en regard du nom de l&#39;élève.

   Menu D&#39;Options ![En Savoir Plus](assets/learner-more-options-menu.png)
   *Menu Plus d’options affichant les actions de l’élève à partir du panneau Participants.*

1. Sélectionnez l’une des actions suivantes :

| **Action** | **Description** |
|----|----|
| **Silence** | Désactive le microphone de l’élève. |
| **En bas** | Supprime l’indicateur de main levée de l’élève. |
| **Envoyer un message privé** | Ouvre une conversation privée avec l’élève. |
| **Supprimer de la session** | Supprime l’élève de la session. |
| **Afficher le profil** | Affiche les informations de profil de l’élève. |
