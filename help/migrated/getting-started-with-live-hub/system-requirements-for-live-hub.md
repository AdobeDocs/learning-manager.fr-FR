# Configuration système

Utilisez la configuration système suivante pour configurer et exécuter des sessions Live Hub dans Adobe Learning Manager. Live Hub utilise le même navigateur, système d’exploitation et configuration matérielle requis que l’environnement de salle de classe virtuelle dans lequel il s’exécute.

Live Hub est disponible dans les sessions de salle de classe virtuelle et ne nécessite pas d’installation client distincte.

| Catégorie | Conditions requises |
|---|---|
| **Navigateurs de bureau** | Dernières versions de Google Chrome, Mozilla Firefox, Microsoft Edge et Safari |
| **Navigateurs mobiles** | Chrome Mobile, Safari Mobile et Samsung Internet |
| **Systèmes d&#39;exploitation** | Windows 10 ou version ultérieure, macOS 15 ou version ultérieure |
| **Résolutions d’écran** | 1920 × 1080, 1366 × 768, 768 × 1024 (tablette) et 375 × 667 (mobile) |
| **Matériel Windows** | 8 Go de RAM minimum, processeur 8 cœurs, Intel® Core™ i5 ou supérieur |
| **Matériel Mac** | Au moins 16 Go de RAM, processeur 4 cœurs, 3,2 GHz ou plus |
| **Réseau** | Connexion large bande stable avec au moins 5 Mbits/s recommandée pour les fonctionnalités audio et vidéo en direct et Live Hub optimisées par l’IA |

>[!NOTE]
>
>Les navigateurs Linux, les appareils Chromebook, Firefox Mobile, Opera (pour poste de travail et mobile), Internet Explorer 11 et les versions de navigateur plus anciennes ne sont pas pris en charge.
